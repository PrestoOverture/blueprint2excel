# PRD: 工程图纸矢量PDF解析器

## 项目定位

桌面应用（Electron壳 + Web UI）+ Python解析引擎，输入SolidWorks/AutoCAD等CAD软件导出的矢量PDF工程图纸，输出结构化质检数据（Excel检查基准书 + 气泡图标注PDF）。

Electron启动本地FastAPI子进程作为后端，前端页面通过localhost调用API。用户全程在图形界面里操作，不需要命令行。

**第一阶段只做矢量PDF**。不做扫描件OCR，不做MES/ERP对接。

## 目标用户

制造业质检工程师——需要从图纸中提取尺寸、公差、孔位信息，生成检查基准书和气泡图。

## 核心用户流程

```
质检员打开桌面应用 → 拖入/选择PDF图纸 → 应用自动判断是否矢量PDF
  → 是：解析文字层，提取所有标注 → 界面预览结果 → 一键导出Excel + 气泡图PDF
  → 否：界面提示"当前版本不支持扫描件"
```

## 功能需求

### P0 — MVP必须有

1. **矢量PDF检测**：判断输入PDF是否含嵌入字体（有=矢量，无=扫描件）
2. **文字对象提取**：提取所有文字内容 + PDF坐标(x, y) + 旋转角度
3. **公差标注重组**：将碎片化的公差文字对象（如"15"、"+0"、".018"分散排布）按空间位置聚类，重组为完整标注（如"15 +0.018/0"）
4. **孔位表解析**：识别并结构化右侧孔位表格（标签、尺寸、深度、螺纹、数量）
5. **技术要求提取**：提取技术要求文字块
6. **标题栏提取**：图号、材料、名称、比例、日期
7. **整体尺寸提取**：轮廓尺寸及带公差的定位尺寸
8. **GB/T 1804公差查表**：根据未注公差等级（m/f/c/v）和标称值自动查出上下偏差
9. **Excel检查基准书导出**：包含所有检测项、标称值、公差、测量工具建议
10. **气泡图PDF导出**：在原图坐标位置叠加编号圆圈标注
11. **Web UI（Electron桌面应用）**：拖拽/选择PDF上传、解析结果预览（尺寸列表、孔位表、气泡图预览）、一键导出Excel和气泡图PDF、错误提示（非矢量PDF等）

### P1 — 第二迭代

- 支持DXF/DWG输入（用ezdxf解析DIMENSION实体）
- 螺纹底孔校验（M3→⌀2.5, M5→⌀4.2, M6→⌀5.0, M8→⌀6.8，自动交叉验证）
- 批量处理（一次传入多个PDF）
- 自定义Excel模板（按客户工厂格式输出）

### P2 — 后续

- 扫描件路线（VLM/OCR + 框选交互）
- MES/ERP回填接口
- 应用打包分发（electron-builder，跨平台安装包）

## 验收标准

- 对SolidWorks导出的矢量PDF，孔位表提取准确率100%（文字层直读，无识别误差）
- 公差叠排重组正确率 ≥ 95%（允许极端碎片化情况下需人工确认）
- 气泡图编号位置与原图标注位置偏差 < 2mm（按比例尺换算）
- 处理单张图纸 < 5秒

## 非目标

- 不做图纸理解/语义分析（不需要"知道"这是什么零件）
- 不做扫描件OCR
- 不做形位公差框格的图形解析（文字层能读到就提取，读不到就跳过）
- 不做独立CLI交付物（解析引擎作为Python库存在，但用户面向的唯一交付物是Web UI + Electron桌面应用）
- 不做跨用户/联网部署（第一阶段是单机本地桌面应用，不做多用户协作或云端服务）
